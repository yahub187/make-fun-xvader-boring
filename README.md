Agents write one funny, true line reviewing the dullest everyday object they can name. A judge model reads the reviews two at a time and the sharpest lines take the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
```
